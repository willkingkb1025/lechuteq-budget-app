## What is Lechuteq Budget?

Lechuteq Budget brings the Six Jars budgeting method into a browser-based personal finance workspace. Use it to arrange income and spending, view cash, bank account, and credit card balances together, and move between past months, the current month, and projected periods.

The tool is built as a local-first, single-file HTML application. Instead of relying on an account or online service, it works with CSV files that you download for data storage and backup. Transaction details can also be pasted from mBank, while the interface is available in both English and Polish.

---

## Core capabilities

- Manage personal finances through a Six Jars budgeting dashboard
- Paste and import transaction information from mBank
- Record income and outcomes for different budgeting periods
- Calculate cash, bank account, and credit card balances
- Examine historical months, the current period, and future forecasts
- Store and export budgeting information as CSV files
- Sort transaction lists and validate entered data
- Select dark mode or use English and Polish localization
- Display currency labels for PLN, EUR, and USD
- Run the complete application offline from one HTML file

## Typical workflow

Use the following sequence for day-to-day budgeting:

1. Launch the single-file HTML application in a web browser.
2. Configure the Six Jars view for the budgeting period being reviewed.
3. Enter income and outcome records, or paste compatible mBank transaction data into the importer.
4. Check the calculated cash, account, and credit card totals.
5. Navigate among historical, current, and forecast month views.
6. Sort the transaction table to locate and review specific entries.
7. Export the latest data as a CSV file for safekeeping or future import.

Once downloaded, the application remains usable without an internet connection.

## Frequently asked questions

### Is an account needed?

No account is specified or required. Lechuteq Budget is intended to run locally in a web browser.

### Does the app support offline use?

Yes. After downloading the single-file HTML application, you can use it offline.

### Where does the budgeting data go?

The application works with downloadable CSV files. Keep your exported files so they can be imported again later.

### Can mBank transaction data be imported?

Yes. The app provides a paste-and-import process for mBank transaction data.

### What currency labels can I use?

The available labels are PLN, EUR, and USD.

### What if an import fails?

Check that the pasted content follows the expected mBank format, read any validation messages, and retry with smaller portions of data if needed.

### Can I switch languages?

Yes. The interface includes English and Polish localization choices.
